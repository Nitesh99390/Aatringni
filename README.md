# Atrangi Live Official – Danish Agency

Modern, mobile-first landing page for the Atrangi Live Danish Agency.

## Features
- Glassmorphism dark theme with animated gradient glows
- Sticky navbar with mobile menu
- Hero with CTA (app download + WhatsApp)
- Features grid (Better Rate / Extra Value / Safe Payments / Instant Top-Up)
- Full coin package table (online vs offline, +5% extra)
- Google Pay QR with one-tap UPI ID copy and `upi://` deep link
- Hiring section with 501 coins joining bonus
- Contact cards, floating WhatsApp button, scroll-reveal animations

## Run locally
```bash
python3 -m http.server 8000
```
Open http://localhost:8000
